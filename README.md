# my-offlineProf
All rights reserved.


인터넷 연결 없이 휴대폰에서 논문을 번역하고 내용에 관해 질문할 수 있는 앱입니다. 출퇴근길이나 이동 중에도 노트북 없이 논문을 읽을 수 있도록 만들었습니다.

논문 PDF를 추가하면 휴대폰에서 실행되는 AI가 내용을 번역합니다. 궁금한 점을 질문하면 논문에서 관련 부분을 찾아 근거가 되는 페이지와 함께 답변합니다!!

## 주요 기능

- **오프라인 사용:** 처음에 Wi-Fi로 AI 모델을 내려받으면 이후에는 인터넷 연결 없이 번역과 질문 기능을 사용할 수 있습니다. 비행기 모드에서도 동작합니다.
- **무료 사용:** 외부 AI 서비스를 이용하지 않으므로 별도의 가입이나 구독, 결제가 필요하지 않습니다~~~
- **기기 내 저장:** 논문에서 추출한 텍스트, 번역문, 질문 기록은 휴대폰에 저장되며 외부 서버로 전송하지 않습니다.
- **한국어/영어 번역:** 논문의 언어를 자동으로 감지해 영어는 한국어로, 한국어는 영어로 번역합니다.
- **단락별 번역:** 현재 보고 있는 단락부터 번역하며, 생성되는 번역문을 바로 확인할 수 있습니다. 번역 결과는 단락별로 저장되므로 중간에 멈춰도 이어서 읽을 수 있습니다.
- **논문 기반 질의응답:** 질문과 관련된 내용을 논문에서 찾아 한국어로 설명하고, `(p.3)`처럼 참고한 페이지를 표시합니다.

## 사용 방법

### 1. 처음 설정하기 (와이파이 연결 필요)

1. 휴대폰에서 앱 주소를 열고 홈 화면에 추가합니다.
   - **iPhone:** Safari의 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.
   - **Android:** Chrome 메뉴에서 **앱 설치**를 선택합니다.
2. **준비** 탭에서 모델 크기를 선택하고 **모델 받기**를 누릅니다.
3. 체크 목록에 **AI 모델이 저장됐어요**가 표시되면 설정이 완료됩니다.

### 2. 논문 추가하기

**서재** 탭에서 **논문 PDF 올리기**를 누른 뒤 파일을 선택합니다.

Android에서 앱을 설치했다면 메일, 드라이브, 파일 앱의 **공유** 기능으로 PDF를 바로 추가할 수도 있습니다.

### 3. 논문 읽기

| 기능 | 사용 방법 |
|---|---|
| 번역 시작·중지 | 화면 상단의 **번역 시작** 버튼을 사용합니다. 현재 화면에 보이는 단락부터 번역합니다. |
| 보기 방식 변경 | **번역**, **같이**(원문과 번역문), **원문** 중 선택합니다. |
| 원문 확인 | 번역된 단락을 누르면 아래에 원문이 펼쳐집니다. |
| 특정 단락 우선 번역 | 단락 아래의 **이것 먼저 번역**을 누르면 해당 단락을 다음 순서로 번역합니다. |
| 단락 설명 | **설명해 줘**를 누르면 해당 단락을 쉽게 풀어 설명합니다. |
| 번역 결과 저장 | **번역본 내보내기**로 번역문과 질문 기록을 파일로 저장하거나 다른 앱에 공유합니다. |

### 4. 논문에 질문하기

**질문** 탭에서는 직접 질문을 입력하거나 미리 준비된 질문을 선택할 수 있습니다.

| 버튼 | 답변 내용 |
|---|---|
| 핵심 요약 | 논문 전체를 다섯 줄로 요약 |
| 연구 문제 | 연구에서 해결하려는 문제와 그 중요성 |
| 방법 | 제안한 방법의 작동 원리 |
| 결과 | 주요 실험 결과와 수치 |
| 한계 | 연구의 한계와 향후 과제 |
| 용어 풀이 | 알아두면 좋은 핵심 용어 다섯 개 |

번역 중에 질문하면 번역을 잠시 중단하고 질문에 먼저 답한 뒤 번역을 이어갑니다.

## AI 모델 선택

| 단계 | 모델 크기 | 권장 기기 |
|---|---|---|
| 빠르게 | 0.5~1.6GB | 구형 휴대폰 또는 메모리 4GB 이하 기기 |
| 권장 | 1.3~2.2GB | 대부분의 최근 휴대폰 |
| 정확하게 | 2.1~3.9GB | 메모리 8GB 이상의 고사양 휴대폰 |

모델 크기에 따라 번역 품질에 차이가 있습니다. **빠르게**를 선택하면 문장이 어색하게 번역되거나 일부 원문이 그대로 남을 수 있어 **권장** 이상의 모델을 추천합니다...

실행 방식의 기본 설정은 **자동**입니다. GPU 실행을 지원하는 환경(최신 Android Chrome, iOS 26 이상 Safari 등)에서는 GPU를 활용하고, 지원하지 않는 환경에서는 CPU로 실행합니다.

## 이동 중 활용 팁

- 출발 전에 와이파이에 연결해 읽을 논문을 추가하고 일부 단락을 번역해 두면, 이동 중에는 읽기와 질문에 집중할 수 있습니다.
- 논문 전체를 번역하기보다 초록, 서론, 결론부터 읽어보세요. **핵심 요약**으로 전체 내용을 파악한 다음 필요한 부분에 **이것 먼저 번역**을 사용하면 됩니다.
- **준비** 탭에서 **번역하는 동안 화면 켜 두기**를 설정하면 번역 중 화면이 꺼지는 것을 방지할 수 있습니다. 화면이 꺼지거나 다른 앱으로 이동해 번역이 멈추더라도 돌아오면 이어서 진행합니다.
- 글자 크기는 **준비** 탭에서 조절할 수 있습니다.

## ..

- 글자를 선택할 수 없는 스캔 이미지 PDF는 아직 지원하지 않습니다.
- 긴 논문을 한 번에 모두 입력해 답변하는 방식은 아닙니다. 질문과 관련된 단락을 찾아 이를 바탕으로 답변하므로, 원하는 답변이 나오지 않으면 질문을 더 구체적으로 작성해 보세요.
- 휴대폰에서 실행하는 소형 AI 모델은 번역이나 답변에 오류가 있을 수 있습니다. 중요한 내용은 표시된 페이지의 원문과 대조해 확인하는 것이 좋습니다.
- 브라우저 데이터를 삭제하면 내려받은 AI 모델과 저장된 논문도 함께 삭제됩니다!
